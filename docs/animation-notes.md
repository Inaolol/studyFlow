# Landing Page Animation Notes

Use this section if the report needs a short explanation of animation and user experience.

## What Is the Landing Animation?

The landing animation is a set of small CSS animations used on the Home page.

## Why This Feature Matters

The animation makes the first screen feel more polished and closer to the original StudyFlow design. It also guides the user's attention from the logo and headline to the main action button.

## What Was Implemented

- floating background color blobs,
- pulsing red dot in the `Built for students` badge,
- headline text that rises into place,
- supporting paragraph and buttons that appear after the headline,
- animated scroll indicator,
- task preview card with a soft entrance animation,
- reduced-motion support for accessibility.
