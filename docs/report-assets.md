## Latest Visual Fix

What Was Fixed?
The home page header and footer were adjusted after visual review.

Why This Fix Was Needed
The header needed to fit the visible browser width, and the footer needed to be simpler for the final report screenshots.

What Was Implemented
- removed the `Sign in` link,
- kept one `Start planning` button on the landing header,
- forced the landing header to span the full viewport width,
- removed the footer technology sentence,
- centered the `StudyFlow - 2026` footer text.

Result
The home page is cleaner, fits better in compact browser widths, and gives clearer screenshots for the final report.
